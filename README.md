# Luna's Moon Loft

I built a tool for helping one revise Japanese using cute games, on an **M5Stack CoreS3** touchscreen, an **M5Stack StickS3** and an **RFID2 reader with NFC stickers**, at an AI hackathon. It is a moonlit desk companion: a little square screen for practising, a pocket-sized pet cat called Luna who grows as you study, and a companion page for the laptop.

Everything on screen is pixel art in one style, and the lesson content is Genki I, Lesson 5.

## What it does

**On the CoreS3 (the square touchscreen)**

- **Kanji practice.** Trace each of the lesson's 14 kanji with a finger on a sheet of calligraphy paper. Hide the guide to write from memory, then tap Check: the firmware compares your strokes with the character's shape and celebrates if they match.
- **Quick quiz.** A clue and two answers. Tilt the device toward the one you want and it is graded instantly; tilt again for the next card. Correct answers earn moon stamps.
- **Talk with Luna.** A live spoken conversation in simple Japanese, through the device's own microphone and speaker.
- **Moon Prism stickers.** Tap an NFC sticker on the reader and the device "transforms" straight into kanji practice.
- **Photobooth.** A 3-2-1 countdown, a snap from the front camera and a decorated frame. Photos never leave your devices.
- **Morning checklist and quotes.** Tick off the day's tasks, or tap for a line of encouragement.

**On the StickS3 (Pocket Luna)**

Luna lives on the stick. The CoreS3 tells her over the air what you just did, and she reacts with a matching animation: painting a kanji, holding a ticked list, juggling moons. Every success feeds her; she grows through six stages, collects a keepsake for each kind of activity, naps when it is quiet, slides around when you tilt the stick and gets dizzy when you shake it. Double-pressing her button is the photobooth's remote shutter.

**On the laptop**

A small local web page shows the same loft, with the checklist, quotes, a Japanese notebook with a typed drill and the same live conversation, and can sync tasks, quotes and the outdoor temperature to the CoreS3 over USB.

## Hardware

| Part | Used for |
|---|---|
| M5Stack CoreS3 (K128) with DinBase | Main screen, touch, tilt, camera, microphone and speaker |
| M5Stack StickS3 (K150) | Pocket Luna, and the remote shutter |
| M5Stack RFID2 Unit (U031-B) and NFC stickers | Moon Prism stickers, on the CoreS3's red Port A |
| M5Stack Gesture Unit (U127), optional | Playing with Luna in the air, on the StickS3's Grove port |

## How the code is organised

| Path | What it is |
|---|---|
| `src/main.cpp` | CoreS3 firmware: screens, touch handling, checklist, quotes, USB protocol |
| `src/kanji.hpp` | Kanji tracing and the stroke check (coverage and tidiness against the rendered glyph) |
| `src/arcade.hpp` | The tilt quiz |
| `src/booth.hpp` | Camera capture and the photobooth |
| `src/arcade_rfid.hpp` | Sticker reader |
| `src/pocket.cpp` | StickS3 firmware: Pocket Luna |
| `src/wand_link.hpp`, `src/wand_radio.hpp` | The packet format and ESP-NOW link shared by both boards |
| `src/art.hpp`, `src/pocket_art.hpp` | Artwork converted to RGB565, generated by the scripts in `tools/` |
| `assets/` | The original artwork |
| `companion.py`, `japanese_session.py` | Laptop companion: a local-only web server, standard library only |
| `Luna_Postcards.html`, `japanese.html`, `*.js`, `loft.css` | The laptop pages |
| `voice/` | My changes to a third-party live-voice SDK example, for conversation on the CoreS3 |
| `test/` | Tests for the companion, the USB framing and the shared board logic |
| `retired/` | An earlier idea, kept for reference |

A few details that might be useful if you are building something similar:

- **Two boards, no network.** The CoreS3 and StickS3 talk over ESP-NOW with a tiny versioned packet format, so nothing needs Wi-Fi. The CoreS3 broadcasts a running total plus the latest event, which lets Luna catch up on anything she missed while switched off.
- **Kanji checking without a stroke database.** The firmware renders the target glyph off-screen, thickens the player's strokes, and measures how much of the glyph is covered and how much ink strays from it. It judges shape, not stroke order.
- **Mostly-transparent art is run-length encoded.** Frames and animation overlays are stored as per-row runs, which keeps a full set of full-screen art inside the app partition.
- **Camera and touch share a bus** on the CoreS3. The photobooth hands the bus to the camera only while it starts, so the countdown can still be cancelled by touch.
- **Two programs on one device.** The firmware lives in the first app slot and the live-voice program in the second. Tapping Talk with Luna reboots into voice, which immediately points the next boot back at the main firmware, so any reset returns home.
- **The laptop can see the device's screen.** A `LUNA/1 SCREEN` command over USB returns the display contents, which made it possible to check layouts without photographing the device.

## Build and run

Firmware uses [PlatformIO](https://platformio.org/):

```sh
pio run -e cores3 -t upload     # CoreS3
pio run -e pocket -t upload     # StickS3
```

Do not install one board's build on the other. `zsh Build_Luna.command` compiles both without installing.

The laptop companion needs only Python 3.9 or newer:

```sh
python3 companion.py
```

Live conversation needs an account with a realtime voice API. Copy `.env.example` to `.env`, fill in your provider's address, key and model names, and start the companion with `Launch_Luna.command`, which loads it. No provider is built in, and no keys are stored on disk by the companion.

To change the artwork, edit the files in `assets/` and regenerate the headers:

```sh
python3 tools/make_art.py
python3 tools/make_pocket_art.py
```
